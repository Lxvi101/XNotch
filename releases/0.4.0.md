XNotch now shows your AI plan limits, with a new AI Usage extension.

- AI Usage shows your Claude Code, Cursor and Codex limits: a tile per provider with percent used or remaining and the time to each reset. Click a tile for model limits, credits, saved resets and extra spend.
- It reads the login each app already keeps on this Mac and never signs in for you. Cursor can also sign in through your own browser from Settings → Extensions → AI Usage.
- Choose which subscriptions to track and what's shown in Settings → Extensions → AI Usage. Readings refresh every 5 minutes, when the page opens with an old reading, and after the Mac wakes.
- The welcome tour now offers the extensions (all start off) and asks for the access the ones you add need.
- The usage requests and decoding adapt CodexBar (MIT); see THIRD_PARTY_NOTICES.md.

These usage endpoints are internal to each provider and may change without notice. If Claude Code keeps its login in the Keychain, choose Always Allow when XNotch asks.

This release is Developer ID signed but not notarized. macOS may require approval in System Settings → Privacy & Security on first launch.
