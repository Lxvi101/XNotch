XNotch 0.15.1 fixes Menu Bar Folders showing icons on the menu bar that are already in a folder, and adds an Always Hidden section.

- Menu Bar Folders: icons in a folder stay hidden after a restart, when their app relaunches or updates, and when a display is connected. Previously they could show on the menu bar and in the folder at the same time.
- Menu Bar Folders: icons that aren't in a folder come back to the menu bar if they end up hidden.
- Menu Bar Folders: a folder that had disappeared from the menu bar shows again.
- Menu Bar Folders: new Always Hidden section for icons you never want to see. Option-click a folder to open it, or right-click a folder and choose Add to Always Hidden.
- Menu Bar Folders: icons can move between folders and Always Hidden from the right-click menu or in Settings.
- Menu Bar Folders: icons are only moved while you aren't using the mouse, so the pointer doesn't jump while you work.
- Menu Bar Folders: with a second display connected, Command-dragging an icon on that display no longer files the wrong icon.
