XNotch now has its icon everywhere, and installs from a DMG.

- The app icon, the notch with its eyes, now shows in Finder, Launchpad and System Settings, not only while XNotch runs.
- New installs download as a DMG: open it and drag XNotch to Applications. Updates still arrive automatically.

This release is Developer ID signed but not notarized. macOS may require approval in System Settings → Privacy & Security on first launch.
