XNotch now updates itself through signed GitHub releases.

- Automatic update checks and downloads, with installation and relaunch handled by Sparkle.
- Update preferences and a Check for Updates button in Settings → About XNotch.
- Signed update feeds and archives, verified before extraction.
- A Dock reminder when an update needs attention.
- Universal app and Folders extension for Apple Silicon and Intel Macs running macOS 14 or later.

Download XNotch-0.2.0.zip, extract it, and move XNotch.app to Applications. Open the app again to show Settings.

Version 0.1 has no updater: install 0.2.0 manually once to receive future automatic updates.

This release is Developer ID signed but not notarized. macOS may require approval in System Settings → Privacy & Security on first launch.
