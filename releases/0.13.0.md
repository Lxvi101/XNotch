XNotch 0.13.0 lets you copy code from Notes with a ⌘-click and copy a whole note as Markdown.

- Notes: ⌘-click inline code to copy it, without the backticks. A plain click still just places the caret.
- Notes: code blocks show a copy button when you hover them.
- Notes: ⇧⌘C copies the whole note as Markdown. It's also in the command bar and the right-click menu.
- Notes: ⌘-click opens a link, and a plain click edits it like normal text.
