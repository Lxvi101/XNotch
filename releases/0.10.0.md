XNotch 0.10.0 adds Notes: Markdown sticky notes in the style of Mote that float over everything, each with a bucket for files, synced through iCloud Drive.

- Notes, a new extension, opens sticky notes out of the notch. Each one is a live Markdown editor: headings, lists, checklists, quotes, links and code show as they'll read, and their syntax appears only where the caret is.
- Code blocks are highlighted for JavaScript, TypeScript, Swift, Python, Rust, Go, the C family, Ruby, PHP, shell, SQL, JSON, CSS, YAML and HTML, and collapse into a card with their language when you're not in them.
- Drop files on a note and they fly into its bucket. Click the bucket to see them, drag them out, Quick Look them, or put a picture into the note, where it shows inline.
- Spaces group notes like folders, and notes from any space can float together. The notch lists a space's notes; ⌘K finds any note, and typing > in it lists actions for the note you're in.
- ⌃⌥N shows and hides every note from any app. Change it, or turn it off, in Settings → Extensions → Notes.
- Settings → Extensions → Notes also has a gliding cursor, spelling and predictive text, and moving or clearing completed tasks.
- Notes sync with iCloud Drive as plain Markdown files in XNotch Notes, a folder per space. Notes are read from your Mac, never straight from iCloud, so a note that hasn't downloaded yet never holds you up, and if two Macs change the same note, both versions are kept.
- Cloud Links are now end-to-end encrypted: your Mac encrypts each drop before uploading, and the key travels only in the link.
- Floating shelves show files from Photos, Mail and Safari as soon as you drop them, and bring each one into focus as it arrives.
- XNotch does less in the background: the media helper stops when you quit, artwork is decoded at the size it's shown, and extensions skip work while the notch is off screen.

Notes is off until you add it in Settings → Extensions. To sync, iCloud Drive must be on; notes go into iCloud Drive › XNotch Notes.
