XNotch 0.12.0 turns links dropped on a shelf into the files behind them, with rules you can write and share, and catches images that browsers fail to hand over.

- Drop a Pinterest pin on a shelf and you get the image in its original size, not a text file with the link. A link to a picture becomes the picture.
- Link rules decide which links become files: the sites and paths a rule covers, and whether the file is the link itself or the page's preview image. Add, edit, reorder and test them in Settings → Shelves → Links, or turn the whole thing off there.
- Rules can be exported and imported as JSON files, all at once or one at a time from a rule's right-click menu.
- Other links land as link files that open the page, instead of text files.
- Images dragged from browsers that promise a file but then don't send it, like Zen and Firefox on ChatGPT, now land on the shelf. Before, they vanished.
- While a linked file downloads, what you dragged waits on the shelf and turns into the file when it's ready.
- Shelves stay responsive when you drop files from network and other slow volumes.
- In Notes, a click just after closing the bucket no longer opens it again.
