XNotch 0.9.0 adds Computer Use: one switch lets AI agents use your Mac, and the notch's eyes watch them work.

- Computer Use, a new extension, installs Wink's computer-use server and adds it to Claude Code, Codex, Cursor, Antigravity, VS Code, Claude Desktop, Windsurf and Gemini CLI. Each app has its own switch in Settings → Extensions → Computer Use, and Remove takes it out of them all again.
- Agents drive apps in the background with a cursor of their own, so your mouse and keyboard stay yours.
- While an agent works, the notch's eyes open under it and keep roughly to the agent's cursor, glancing at the window it's reading now and then. They squint happily and close when it's done.
- Settings → Extensions → Computer Use shows which agents are using the Mac right now.
- Extensions can open the notch's eyes and point them at something on screen (XNotchKit 1.7.0).

Computer Use is off until you add it in Settings → Extensions. Each app you use it from asks for Accessibility and Screen Recording the first time an agent works through it.
